B. JUDUL PROGRAM
Program Menghitung luyas persegi panjang

C. DESKRIPSI MASALAH
program ini dibuat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang dimasukan oleh pengguna

D. TUJUAN PROGRAM

membantu pengguna menghitung luas persegi panjang secara cepat dan tepat.

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
   - Panjang persegi panjang (p)
- Lebar persegi panjang (l)

2. PROSES:
- Menghitung luas persegi panjang
- Rumus : luas = pangjang * lebar.

3. OUTPUT:
   - Menampilkan hasil luas persegi panjang

F. ALGORITMA / PSEUDOCODE



MULAI

   1. Deklarasikan variabel luas,panjang,lebar
   2. Masukkan nilai panjang.
   3. Masukan nilai lebar.
   4. Hitung luas = panjang * lebar.
   5. Tampilkan nilai luas.
